Hosting

This website is hosted via Cloudflare Pages as a static site (HTML, CSS and JavaScript files only — no server-side backend). Cloudflare processes technically necessary server log data (e.g. IP address, timestamp, requested file) to deliver and secure the site. This processing is necessary to provide the website (Art. 6(1)(f) GDPR).

Traffic measurement with Cloudflare Web Analytics

We use Cloudflare Web Analytics for anonymized measurement of page views. The service sets no cookies and stores no information on your device. Only aggregated, non-personal data is collected (e.g. page views, load times, rough geographic origin at country level derived from the IP address). The IP address itself is not stored.

Since no access to device information occurs and no cookies are set, no consent under the ePrivacy Directive is generally required. Processing is based on our legitimate interest in privacy-friendly traffic measurement (Art. 6(1)(f) GDPR).

Traffic measurement with Umami Cloud

In addition to Cloudflare Web Analytics, we use Umami Cloud (operated by Umami Software Inc., with servers located in the US and EU) for more detailed, privacy-focused traffic and interaction analysis. Like Cloudflare Web Analytics, Umami sets no cookies and does not use local storage or any other on-device identifier to track visitors. It does not track users across different websites.

Umami collects: the page URL visited, the referring site (if any), browser type, operating system, device type, and country-level location derived from your IP address. The IP address itself is used only momentarily to determine the country and is not stored. No personally identifiable information is collected.

Since no cookies are set and no persistent device identifiers are used, no consent under the ePrivacy Directive is required. Processing is based on our legitimate interest in understanding how the site and its calculator are used, in order to improve them (Art. 6(1)(f) GDPR).

Cookies

This website sets no cookies — neither technically necessary ones nor tracking or marketing cookies.

Contact form

This website has no contact form. Contact happens exclusively via direct email to the address listed in the Imprint; any data submitted that way is used solely to handle the inquiry.

The liquidation calculator

The calculator runs entirely in your browser. Every value you enter (margin, leverage, maintenance margin rate, fees, funding rate, price) is processed locally on your device using JavaScript and is never transmitted to our servers or any third party — the site makes no network requests to submit or store your inputs.

Your rights

Under the GDPR, you have the following rights regarding any personal data that is processed: access (Art. 15), rectification (Art. 16), erasure (Art. 17), restriction of processing (Art. 18), data portability (Art. 20), and objection to processing (Art. 21 GDPR). Contact us at the email above to exercise these rights. You also have the right to lodge a complaint with a data protection supervisory authority.

Changes to this policy

This privacy policy will be updated as soon as the site's actual functionality changes — for example, if a contact form, user accounts, or additional analytics tools are introduced.
